# راهنمای ساخت فایل نصبی اندروید (APK) در Android Studio

این پوشه شامل سورس کامل پروژه اندروید برای ساخت فایل APK است.

> **نکته بسیار مهم:** شما بدون نیاز به نصب APK هم می‌توانید از این برنامه استفاده کنید! کافیست کابل USB را وصل کرده، USB Tethering را روشن کنید و در مرورگر Chrome گوشی آدرس سرور (مثلاً `http://192.168.42.129:8000`) را باز کنید و گزینه **"Add to Home Screen"** را بزنید تا دقیقاً مانند یک اپلیکیشن نصب‌شده تمام‌صفحه باز شود.

---

### مراحل ساخت فایل APK با اندروید استودیو:

1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کنید و همین پوشه `android_app` را باز کنید.
3. منتظر بمانید تا Gradle پروژه را Sync کند.
4. از منوی بالا به مسیر زیر بروید:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`
5. پس از چند ثانیه فایل APK در مسیر زیر ساخته می‌شود:
   `android_app/app/build/outputs/apk/debug/app-debug.apk`
6. فایل APK را روی گوشی اندروید خود انتقال داده و نصب کنید.
